2 · El caso

Un solo caso atraviesa el mapa, el informe de ejemplo y las herramientas. Léanlo antes de recorrerlas. Carpetas documentos/2_caso y modelo.

CasoDossier de Red Salud Andina La organización simulada de respaldo: sistemas, cifras, episodios, restricciones y las dos alternativas de la Unidad 2. ArchiModelo del caso (.archimate) Se abre con File → Open en Archi. 41 elementos, 39 relaciones y las cuatro vistas armadas y encadenadas. No usen File → Import con este archivo. Open ExchangeModelo del caso (.xml estándar) El mismo modelo en el formato de The Open Group. Se abre con File → Import → Model From Open Exchange File…, en Archi o en otra herramienta ArchiMate.
